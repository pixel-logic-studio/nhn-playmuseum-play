# NHN Playmuseum — protected web edition

Password-encrypted standalone game. The source game is maintained separately in a private repository. No password or unencrypted game assets are stored here.

Powered by [StatiCrypt](https://github.com/robinmoisson/staticrypt) (MIT).

After successful entry, the encrypted page remembers the unlock key only for the current browser tab. Refreshing or restarting in that tab unlocks automatically; the plaintext password is never saved.
